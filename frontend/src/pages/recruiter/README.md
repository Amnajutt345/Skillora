# Skillora - Recruiter Module

## Overview

The Recruiter Module is a part of Skillora, a platform designed to connect recruiters with developers. It provides recruiter-related frontend pages for managing jobs, exploring developers, reviewing requirements, and accessing recruiter profile and settings.

## Pages

### Dashboard
The main landing page of the recruiter module.

### Candidate
Candidate-related page for recruiter activities.

### Company Profile
Page for displaying and managing company profile information.

### Create Job
Page for creating new job postings.

### Developers
Page for browsing developers.

### Help
Help and support page for recruiters.

### Jobs
Page for recruiter job management.

### Requirements Review
Page for reviewing recruitment requirements.

### Settings
Page for managing recruiter settings.
